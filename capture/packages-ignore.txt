# Packages that show up as manually installed but are not choices worth
# recording — Ubuntu's own base system, language packs, drivers, and the
# transitive things a desktop install marks manual.
#
# This file exists because `apt-mark showmanual` lists 132 packages on this
# machine while lib/manifest.sh declares 27. Without a filter, capture/packages.sh
# would report a hundred lines of noise every run and you would stop reading it.
#
# One glob per line. `capture/packages.sh --ignore <pkg>` appends here.
# Anything matching is hidden from the "installed but not declared" report.
