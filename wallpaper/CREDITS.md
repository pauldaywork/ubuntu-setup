Earlier commits also carried Kirokaze's *Absent Look* and *Tight Room*.

The odd file names are DeviantArt's: the leading `d…` token is the deviation id
in base 36 (drop the `d`), which is how the untitled ones above were traced back.
The `wallhaven-<id>` files are from wallhaven.cc/w/<id>, whose page gives the
source link. Wallhaven's API returns that link and the tags, which is where the
ArtStation links and the "per Wallhaven's tags" artists come from. The unknown
GIFs came uncredited from the wallpaper repos D3Ext/aesthetic-wallpapers,
JoydeepMallick/Wallpapers and dharmx/walls.
